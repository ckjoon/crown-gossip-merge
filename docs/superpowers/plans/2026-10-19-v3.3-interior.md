# v3.3 인테리어 개편 Implementation Plan

**Goal:** 성 인테리어 복구가 "보상답게" 보이도록 — 실제 3D 모델(CC0), 꽉 찬 화면, 복구 전/후 대비, 라벨 정리.

**Spec:** 2026-10-19 대화의 가십하버 비교 분석 (사용자 승인: "ㅇㅋ 좋아 진행해 전부"). 문제: (1) 인테리어가 후져서 보상이 보상답지 않음, (2) 버튼·설명 과다.

**Tech:** Three.js r186 GLTFLoader (three/examples/jsm), 기존 toon/outline 파이프라인.

## Global Constraints
- 에셋은 CC0만: Quaternius Fantasy Props MegaKit(Standard), Quaternius Stylized Nature MegaKit(Standard), Kenney Food Kit. 출처는 `public/models/CREDITS.md`.
- 텍스처는 BaseColor만, 최대 1024px. 노멀/ORM 제거. 파일마다 6MB 미만(PWA 프리캐시 상한).
- 오프라인에서도 성 화면이 떠야 함 → glTF/bin/jpg 프리캐시.
- 세이브 형식·규칙(core) 변경 없음.
- 한국어 UI/주석/커밋.

## Review Focus
- 모델 로딩 전/실패 시: 절차적 가구로 대체 (빈 방·흰 사각형 금지).
- 복구 연출(playRestore·스타일 미리보기)은 모델이 이미 캐시에 있을 때 동기적으로 그려야 함.
- 텍스처 있는 재질의 툰 변환이 map·colorSpace를 유지.
- 모바일 부하: 구역당 모델 수·그리기 호출.
- 오프라인 새로고침 후 성 화면.

## Tasks
1. **툰 변환이 텍스처를 유지** — `toon.ts` toToon이 map/alphaTest/vertexColors 복사. 테스트 RED→GREEN.
2. **모델 준비 스크립트 + 에셋** — `tools/prepare-models.mjs`: 선택 모델 목록 → `public/models/{props,nature,food}/`, 텍스처 리사이즈(sips)·JPEG/PNG, 노멀/ORM 제거. `src/views/castle/models/manifest.ts` 모델 이름 목록. vite 프리캐시 패턴에 gltf/bin/glb/jpg 추가.
3. **모델 라이브러리 + 장소 레시피** — `ModelLibrary`(preload(zone) → Promise, clone(name) 동기), `SPOT_RECIPES` 데이터 표(장소별 모델 배치·스타일 3종). buildSpotFurniture: 레시피 모델 + 절차적 구조물(분수·아치 등) 혼합, 미로딩 시 기존 절차적 가구. 테스트: 20곳 레시피 존재·모델 이름이 manifest에 있음·스타일 3종이 서로 다름.
4. **방 연출** — 카메라를 당겨 방이 화면을 채우게, 장소 라벨 5개 → 다음 복구 장소 하나만 반짝이는 표식, 미복구 장소에 먼지·거미줄·부서진 상자, 복구 시 주변 소품(화분·촛불)이 함께 생김, 성 화면 하단 패널 정리.
5. **릴리스 v3.3.0** — 버전·패치노트, 전체 테스트 + E2E(오프라인 포함), 전체 리뷰, 수정, main 병합·배포 확인.
