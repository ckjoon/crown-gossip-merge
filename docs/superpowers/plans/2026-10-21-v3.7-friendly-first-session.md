# v3.7 친절한 첫 경험 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 새 플레이어가 막히지 않고 제1화 복구까지 가도록 안내하고, 잘리는 UI와 치우친 성 카메라를 고친다.

**Architecture:** 저장 필드는 추가하지 않는다. 안내는 모두 현재 상태에서 계산한다.
- **core:** `findMergePair`를 추가한다. 순수 조회다.
- **views:**
  - `coach.ts`: 순수 함수로 단계를 계산한다.
  - `Coach.svelte`: 화면에 띠를 그린다.
  - `BoardView.nudge`: 타일 넛지 연출이다.
  - `modules.frameZone`: 투영 기준으로 카메라를 맞춘다.

**Tech Stack:** TS, Svelte 5, PixiJS 8, Three.js, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-v3.7-friendly-first-session-design.md`

## Global Constraints
- 세이브 키·필드는 바꾸지 않는다. 새 저장 필드는 없다.
- 경제 수치는 바꾸지 않는다. `balance.test.ts`는 그대로 통과해야 한다.
- 한국어 UI·주석·커밋. 커밋은 `feat(v3.7.0): ...` 형식이다.
- 코치 띠는 모달이 아니다. `.gh-modal`을 쓰지 않고, 클릭을 막지 않는다.

## Review Focus
- **기존 세이브(제1화 완료):** 코치가 전혀 보이지 않는다. → Task 3 unit
- **코치·넛지 중 드래그·탭:** 넛지가 즉시 멈추고, 타일 위치와 크기가 원래대로 돌아온다(드래그 중인 노드를 건드리지 않음). → Task 2 E2E 드래그 합성
- **보드 가득 + 합칠 쌍 없음:** `stuck` 문구가 나오고 넛지는 없다. → Task 3 unit
- **새 게임이 아닌데 `lastSeenVersion`이 null인 세이브:** 지금처럼 업데이트 노트를 띄운다(isNew만 건너뜀). → Task 1 코드 확인
- **카메라:** 구역 전환·복구 후 다시 맞출 때 팬 범위가 바뀐 home 기준으로 계산된다. → Task 4 unit

### Task 1: 새 게임 업데이트 노트 생략 + 알림 다듬기
- **main.ts:** `isNew`이면 `store.dispatch(markVersionSeen, { version: APP_VERSION })`.
- **`ui.svelte.ts` `toast`:**
  - 같은 문구가 살아 있으면 새로 쌓지 않고 만료 시간을 늘린다.
  - x 보정은 `half = min(w − 24, 340) / 2`로 한다.
- **legacy.css `.fx-float-text`:** `max-width: calc(100vw - 24px); white-space: normal; text-align: center`.
- **Test:**
  - unit `tests/unit/toast.test.ts`: 같은 문구 두 번이면 1개, 긴 문구 x는 화면 가운데 쪽.
  - E2E `tests/e2e/first-session.spec.ts`: 새 게임에 `.gh-modal`이 없다. 보드를 가득 채우고 탭하면 알림 상자가 화면 안에 있다.

### Task 2: 합성 쌍 찾기 + 보드 넛지 + 대기 힌트
- **core/actions/board.ts:** `findMergePair(s): [number, number] | null`. 우선순위는 spec C를 따른다.
- **BoardView:**
  - `nudge(cells: number[])`: 해당 노드에 gsap 반복 트윈(서로를 향해 6px, 기울기 ±0.12, yoyo)을 건다.
  - `stopNudge()`는 트윈을 끝내고 위치, 회전, 크기를 원래대로 돌린다.
  - `handleDown`과 `render`의 노드 재생성 때 정리한다.
- **BoardCanvas:** 마지막 입력 후 5초 대기 타이머로 `findMergePair`를 넛지한다. `boardFull` 거절이면 즉시 넛지한다.
- **Test:**
  - unit `tests/unit/mergePair.test.ts`: 우선순위 ①②③, 수집품 제외, 최대 레벨 제외, null.
  - E2E: 넛지 중 드래그 합성이 정상 동작한다(기존 new-game 흐름 + 대기 후 드래그).

### Task 3: 첫 복구 코치
- **`views/ui/coach.ts`:** `coachStep(s): { step, cells, text } | null`. spec D 표를 따른다.
- **`Coach.svelte`:** 주문 아래에 띠를 그린다. step별로 다음을 표시한다.
  - 주문 카드 `.coach-pulse`
  - 성 버튼 `.coach-pulse`
  - 보드 넛지
- **CastleScreen:** `castle` 단계면 `.story-next-btn`에 `.coach-pulse`를 붙인다.
- **v3.css:** `.coach-bar`, `.coach-pulse` 애니메이션(reduceMotion이면 테두리만).
- **Test:**
  - unit `tests/unit/coach.test.ts`: 단계 5가지, 제1화 완료면 null.
  - E2E: 새 게임 spawn → 합성 → 주문 준비 → serve → 코인 → castle 문구 → 제1화 후 띠가 없다.
